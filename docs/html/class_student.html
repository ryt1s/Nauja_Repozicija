Detailed Description

Išvestinė klasė aprašanti studentą.

Palaiko "Rule of Three": kopijavimo konstruktorių, priskyrimo operatorių ir destruktorių. Apskaičiuoja galutinius balus pagal vidurkį ir medianą.
